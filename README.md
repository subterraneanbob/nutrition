# Нейросеть для предсказания калорийности блюд

Мультимодальная нейросеть, которая предсказывает калорийность блюда по его фотографии, массе порции и ингредиентам.

Для подготовки изображений использовались следующие аугментации: `Resize`, `HorizontalFlip`/`VerticalFlip`, `RandomRotate90`, `RandomBrightnessContrast`, нормализация.

Архитектура модели:

- энкодер изображений блюд `tf_efficientnetv2_m.in21k`
- энкодер текстового описания игредиентов `all-MiniLM-L6-v2`
- проекционные слои для приведения полученных эмбеддингов к одинаковой размерности
- конкатенация эмбеддингов и финальное предсказание

При обучении использовался `L1Loss` в качестве функции потерь, `AdamW` для оптимизации. Целевая метрика - MAE. Процесс обучения останавливается, если в течение нескольких эпох не было улучшения целевой метрики. Модель с лучшим результатом сохраняется в `checkpoints/best_model.pt` (доступна по [ссылке](https://disk.yandex.ru/d/CBMpJ7zenwB6Cw))

Структура репозитория:

- `checkpoints` - сохранённый checkpoint лучшей модели
- `data` - датасет (`images`, `dish.csv`, `ingredients.csv`)
- `scripts/config.py` - конфигурация по умолчания для обучения модели
- `scripts/dataset.py` - классы для подготовки и загрузки данных
- `scripts/model.py` - классы и функции для обучения и оценки качества модели
- `scripts/utils.py` - вспомогательные функции

Для работы использовались:

- Python 3.13
- библиотеки pytorch, torchmetrics, timm, transformers, albumentations, pillow, pandas, seaborn
